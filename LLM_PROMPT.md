# AI Styling Instructions (KTH Quarto)

This repository contains the KTH branding assets. When asked to generate content, adhere to these rules:

1. **Reference files:** 
Refer to `/_extensions/kth-quarto/brand.yml` for color palette and typography defaults.

2. **Styling:** 
Follow the CSS/SCSS structure defined in the `/_extensions/kth-quarto` directory.
Use the KTH logo defined in `/_extensions/kth-quarto/brand.yml`
Place information on the the data source and LLM-model top right in the header. 

3. **Format:** 
Output content as Quarto-compatible Markdown, ensuring all YAML front-matter is present and accurate to the template.

4. **Constraint:** 
Never override the KTH color hex codes defined in the theme files.
